  returns the unwrapped `data`.
- Token handling: the in-memory access token is attached as `Authorization: Bearer ...`
  when present (header omitted otherwise); every request sends `credentials: "include"`
  so the httpOnly refresh cookie reaches POST /auth/refresh; JSON bodies get a
  Content-Type automatically.
- Refresh-on-401: a 401 triggers exactly ONE refresh attempt (single-flight — concurrent
  401s share one refreshPromise) and then retries the original request with the new
  token. The retry cannot itself refresh, so a second 401 throws instead of looping.

  `redirectToLogin` -> window.location.assign('/login')), and throws a structured
  ApiError. Auth endpoints (register/login/refresh/logout) bypass the refresh flow so
  invalid credentials surface as a 401 ApiError with no redirect.
- ApiError exposes statusCode / error / messages[] / path. Typed methods: register,
  login, logout, me, listTasks(page/limit/completed), createTask, getTask, updateTask,
  deleteTask. Exported `apiClient` singleton (baseUrl from NEXT_PUBLIC_API_URL) plus a
